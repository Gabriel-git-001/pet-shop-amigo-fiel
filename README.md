# 🐾 Pet Shop Amigo Fiel

Site institucional responsivo para um pet shop fictício, desenvolvido como projeto acadêmico de colaboração com Git/GitHub.

## Visão geral

- **Serviços:** banho, tosa e cuidados especiais.
- **Produtos:** alimentação, brinquedos e higiene.
- **Horários:** tabela de funcionamento (dados ilustrativos).
- **Localização:** seção com espaço para endereço e mapa reais.
- **Contato:** link de e-mail demonstrativo.

> **Atenção:** horários, endereço e e-mail são ilustrativos. A equipe deve substituí-los antes de publicar como negócio real.

## Tecnologias

- HTML5 semântico
- CSS3 responsivo
- JavaScript (menu mobile e ano automático)
- Git, GitHub e Netlify ou Vercel

## Executar localmente

Abra `index.html` no navegador. Nenhuma dependência é necessária.

## Integrantes e responsabilidades

| Integrante | Responsabilidade | Branch |
| --- | --- | --- |
| [Nome 1] | Estrutura HTML e conteúdo de serviços | `feature/servicos` |
| [Nome 2] | Estilo visual, responsividade e produtos | `feature/produtos` |
| [Nome 3] | Horários, localização, JavaScript e revisão | `feature/contato` |

Preencha os nomes reais e registre os commits na conta GitHub de cada integrante.

## Fluxo de colaboração

1. Criar repositório GitHub e configurar `main`.
2. Cada integrante cria uma branch de funcionalidade a partir de `main`.
3. Cada integrante realiza commits próprios com mensagens descritivas.
4. Abrir Pull Requests para `main`, revisar e fazer merge.
5. Resolver conflitos quando ocorrerem. Não fabricar conflitos nem histórico.
6. Testar e publicar a branch `main` no Netlify ou Vercel.
